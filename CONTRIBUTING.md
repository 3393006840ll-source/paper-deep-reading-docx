# Contributing

Contributions, reproducible bug reports, and focused documentation improvements are welcome.

## Before opening an issue

- Use the latest files from the repository.
- Describe the operating system, Python version, installed dependency versions, and the command or Codex prompt used.
- Explain the expected behavior and the actual behavior.
- Do not upload copyrighted papers, private documents, credentials, or other sensitive data. Use a minimal sanitized description instead.
- For evidence or layout problems, include the source location, output section, and a short reproducible description.

## Pull requests

- Keep changes focused and preserve the complete Skill bundle structure.
- Do not change the invocation name `$paper-deep-reading-docx` without a compatibility note.
- Do not invent paper facts, numerical results, formulas, or evidence locations.
- Update the README or examples when user-facing behavior changes.
- Run the relevant script checks before submitting.

## Review priorities

Changes are reviewed for:

1. Evidence traceability and factual restraint.
2. Compatibility with the documented Codex workflow.
3. Clear Chinese and English user-facing documentation.
4. Reproducible validation and maintainable file structure.
