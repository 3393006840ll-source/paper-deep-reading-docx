# Changelog

All notable changes to `paper-deep-reading-docx` are documented here.

## [0.1.1] - 2026-08-06

### Changed

- Generalized the Skill trigger description and evidence guidance for academic papers across disciplines.
- Reframed method branches as optional analysis paths selected by paper type.
- Updated the output specification to connect findings with the user’s research direction or practical question.
- Preserved compatibility with documents using the legacy research-direction heading.
- Expanded the README with bilingual installation, verification, and usage guidance.

### Added

- GitHub Actions quality checks for Python 3.10, 3.11, and 3.12.
- Temporary PDF extraction and DOCX structural-audit smoke tests.
- `CITATION.cff` metadata for academic and software citation.

## [0.1.0] - 2026-08-04

### Added

- Initial public release of the complete Codex Skill bundle.
- Evidence rules and a fixed Word output specification.
- Page-separated PDF evidence extraction with `scripts/extract_pdf_evidence.py`.
- Structural DOCX auditing with `scripts/audit_docx.py`.
- Bilingual installation and usage documentation.
- Apache-2.0 licensing and contribution guidance.
