# Changelog

All notable changes to `paper-deep-reading-docx` are documented here.

## [0.1.0] - 2026-08-04

### Added

- Initial public release of the complete Codex Skill bundle.
- Evidence rules and a fixed Word output specification.
- Page-separated PDF evidence extraction with `scripts/extract_pdf_evidence.py`.
- Structural DOCX auditing with `scripts/audit_docx.py`.
- Bilingual installation and usage documentation.
- Apache-2.0 licensing and contribution guidance.
